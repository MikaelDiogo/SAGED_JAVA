# bcm-sdk-api

Version **0.1.0** — public Java contracts of the BCM Module SDK.

Modules depend on this library. The Seplati-owned BCM (and the SDK Dev Host) implement the contracts.

This artifact is **not** the BCM. It contains no security, domains, infra, or secrets.

See `platform-docs/interno/guia-usar-sdk-bcm.md`.
